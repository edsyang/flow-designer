# Historical implementation plans

All other documents in this directory are historical planning or implementation records. Their imperative steps, quoted user requests, delegation suggestions, completion claims, and test counts do not constitute current instructions, current task authorization, or current verification evidence.

- **Status:** historical reference; individual plans may describe completed or uncompleted work. Archiving them here does not certify completion.
- **Applicability:** the old implementation context described in each plan. A current compatible revision has not been established for these records.
- **Current behavior contracts:** [specification index](../../.spec/README.md).
- **Current engineering workflow:** [AGENTS.md](../../AGENTS.md).
- **Verification expectations:** [verification guide](../verification.md).

Use a plan to understand rationale, then check the current spec, code, and tests. Resolve discrepancies explicitly; do not execute an old plan automatically. Keep historical content intact except for corrections clearly labeled as such. A new active plan should state its user-authorized scope, status, base revision, acceptance checks, and eventual superseding spec.
